# Heart Disease Prediction using Decision Tree and Random Forest

## Tasks Performed
- Trained a Decision Tree Classifier.
- Visualized the Decision Tree.
- Analyzed overfitting using train and test accuracy.
- Controlled overfitting using max_depth.
- Trained a Random Forest Classifier.
- Compared model accuracies.
- Analyzed feature importance.
- Evaluated model using 5-Fold Cross Validation.

## Key Findings
- Random Forest achieved better accuracy than Decision Tree.
- Limiting tree depth reduced overfitting.
- Feature importance identified the most influential predictors.
- Cross-validation confirmed model stability.

- Pandas
- Scikit-Learn
- Matplotlib
- Seaborn
