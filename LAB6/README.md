# KNN Classification on Iris Dataset

## Overview
Implemented the K-Nearest Neighbors (KNN) algorithm on the Iris dataset to classify flower species.

## Steps Performed
- Loaded and preprocessed the Iris dataset.
- Normalized features using StandardScaler.
- Split data into training and testing sets.
- Trained KNN models with different K values.
- Evaluated performance using Accuracy Score and Confusion Matrix.
- Visualized decision boundaries using selected features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Conclusion
This project demonstrates the use of KNN for multiclass classification. Feature normalization improved distance-based learning, and decision boundary visualization helped understand how the classifier separates different classes.
