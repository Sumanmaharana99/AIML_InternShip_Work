# TASK 2 Elevate Labs AIML

## Tasks Performed

* Loaded and explored the Titanic dataset.
* Generated summary statistics using Pandas.
* Created histograms for Age, Fare, SibSp, and Parch.
* Created boxplots for Age and Fare to detect outliers.
* Analyzed feature relationships using Pairplot and Correlation Matrix.
* Studied the impact of Age, Fare, and Pclass on Survival.

## Key Findings

* Most passengers were between 20–40 years old.
* Higher fare passengers had better survival chances.
* First-class passengers were more likely to survive than third-class passengers.
* Fare distribution is highly right-skewed and contains several outliers.
* Age shows a weak relationship with survival.
