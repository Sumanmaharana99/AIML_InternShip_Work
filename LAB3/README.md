Tasks Performed
Imported and preprocessed the Titanic dataset.
Split data into training and testing sets.
Trained a Linear Regression model using Scikit-Learn.
Evaluated the model using MAE, MSE, and R² Score.
Visualized the regression line between Age and Fare.
Results
MAE: 19.78
MSE: 946.34
R² Score: 0.388
Key Findings
Age has a weak positive relationship with Fare.
The model explains about 38.8% of the variation in Fare.
Several high-fare outliers are present in the dataset.
